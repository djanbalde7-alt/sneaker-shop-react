# Sneaker Shop — React

Boutique en ligne construite en React, avec chargement des produits
depuis une API, recherche en direct et panier persistant.

## Fonctionnalités

- Catalogue chargé depuis la Fake Store API
- Recherche en temps réel
- Page de détail par produit
- Panier global avec compteur et total
- Interface responsive

## Stack

React · React Router · TanStack Query · Tailwind CSS · Vite

## Lancer le projet

```bash
npm install
npm run dev
```
